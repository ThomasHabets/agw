## General

* One logical change per commit
* The protocol spec is at <https://www.on7lds.net/42/sites/default/files/AGWPEAPI.HTM>
* The protocol spec may contain errors. Document these in spec-errors.md as
  you find them.

## Commit messages

* Max 72 characters per line
* First line short description
* Further commit message elaborates on why with examples where possible
* If a change is just to an example, prefix with "examples/examplename: "
* If a change is only one api, prefix with e.g. "v1: " or "async: "

## Presubmits

NEVER skip presubmits.
